# 永恒之魂 (Eternal Soul)

**一件"终极饰品" —— 戴上它，等于戴上全世界。**

适用于 Minecraft 1.20.1 / Forge，依赖 [Curios](https://www.curseforge.com/minecraft/mc-mods/curios)。

## 功能

永恒之魂是一件可放入**任意饰品栏**的饰品（下界之星外观，史诗品质）。佩戴后，你将同时拥有游戏中**所有饰品的效果**——包括各模组饰品的主动与被动效果，无需逐个收集。

佩戴瞬间，饰品栏会出现大量饰品：

- 这些饰品只是效果来源，**无法取出、移动或放入物品**，不用担心丢失或复制
- 它们**随永恒之魂的佩戴而生、卸下而灭**——卸下永恒之魂即可全部移除
- 已实际佩戴的饰品不会重复生效

## 饰品管理列表

按 **K** 键（默认，可在按键设置中修改）打开饰品列表界面：

- 顶部**搜索栏**，支持按名称模糊搜索
- 每条栏目左侧显示饰品贴图，附名称与槽位类型
- **点击条目即可开关**该饰品的效果（"模拟中" / "已关闭"）
- 开关状态永久保存，跨死亡、跨重登不丢失

## 其他

- 创造模式物品栏有专属标签页，也可用 `/give @s eternalsoul:eternal_soul` 获取
- 内置中英双语

## 安装

1. 安装 [Curios](https://www.curseforge.com/minecraft/mc-mods/curios)（1.20.1 版本）
2. 将 `eternalsoul-x.x.x.jar` 放入 `mods` 文件夹
3. 进入游戏，领取你的永恒之魂

## 构建

```bash
./gradlew build
```

需要 JDK 17，产物位于 `build/libs/`。
